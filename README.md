Antonic Agent

Antonic Agent helps you and your team run AI agents, skills, and workflows — right from your desktop.

What It Does

Local-first, cloud-ready: Antonic Agent runs on your machine in one click. Send a message instantly.
Composable: Use it as a desktop app, or connect via WhatsApp, Slack, or Telegram. No lock-in.
Shareable: Start solo, then share. One command spins up an instantly shareable instance for your team.
Extensible: Install skills and plugins to extend what your agents can do.

Features

Host mode — run agents locally on your computer
Client mode — connect to a remote server by URL
Sessions — create and manage AI sessions easily
Live streaming — see real-time updates as your agent works
Execution plan — visualize your agent's progress as a timeline
Permissions — control what your agent is allowed to do
Templates — save and reuse common workflows
Skills manager — install and manage agent skills

Quick Start
Download the installer from the releases page and run it. No technical setup required.
